#Job Application Tracker

A Python command-line application designed to help users organize and track their job applications.

##Features

-Add new job applications.
-Track company names and job positions.
-Update application statuses.
-View all saved applications.
-Automatically save data in a JSON file.
-Record application dates.

##Technologies Used

-Python 3
-JSON
-Dataclasses
-Argparse

##Available Commands

###Add an application:

```bash
 python main.py "Google" "Python Developer"
```

###List application:
```bash
    python main.py list
```

###Update application status:
```bash
    python main.py update 1 interview
```
